# Jupiter JLP with a Hyperliquid hedge

Jupiter's JLP pool earns 75% of trading fees and acts as the counterparty to leveraged traders. A long JLP position could use BTC, ETH and SOL perpetuals to reduce directional risk while keeping the net fee and trader P&L exposure. The hedge needs separate cash collateral. The pool can change its stablecoin composition, and collateral, short-funding and cross-chain liquidity risks can remain even if the crypto hedge matches its exposure. Neutral Trade and Vectis provide concrete precedent for this type of hedge. [Jupiter protocol disclosures](https://www.jup.ag/lend/sentora/transparency) · [Neutral Trade strategy and closure](https://www.neutral.trade/strategies/jlpdn) · [Vectis hedge methodology](https://app.vectis.finance/Vectis%20JLP%20Navigator%20Vault%20-%20Whitepaper.pdf)

Jupiter's documented current custody weight is accounting AUM by asset. That figure includes state associated with trader positions. A delta hedge needs the units of owned and committed assets, short size and entry basis, JLP supply, and the contemporaneous oracle. For example, positions locked by the pool as trader payout liquidity and synthetic short exposure change the pool's response to a price move. Using frozen target weights would leave an unmeasured net exposure. [Jupiter custody account](https://developers.jup.ag/docs/perps/custody-account) · [Gauntlet Jupiter dashboard methodology](https://discuss.jup.ag/t/gauntlets-real-time-dashboard-explained/20114)

On November 23, 2026, the official `/v1/jlp-info` endpoint returned current NAV, current and target weights, owned and locked balances, and global short size and average price. The unmodified request and two requests with a September 3, 2026 date or Unix timestamp returned byte-identical payloads. The visible APR timestamp describes the last APR update. It does not prove when the rest of the state was observed. A `/v1/jlp-info/history` probe returned HTTP 404, and the published API inventory disclosed no historical custody and share-state endpoint. Solana's public RPC account route returns account data at its response context slot and allows a minimum context slot. It does not expose a historical state selector. [Jupiter public API specification](https://perps-api.jup.ag/v1/docs) · [Solana account RPC](https://solana.com/docs/rpc/http/getaccountinfo)

An advertised source of daily Jupiter API snapshots begins September 2, 2026 and lists aggregate open interest and custody AUM, but its public JSON route returned HTTP 403 from the CLI and HTTP 401 from the browser tool. Its documented schema does not include locked balances or short entry basis. Separately, Trawl advertises historical decoded transactions and publishes schema samples. Those samples do not provide complete dated custody state paired with tradable JLP prices. The available time series therefore does not establish a point-in-time hedge or execution cost over multiple holdouts. A current router quote can price one proposed swap but cannot establish what historical entry and exit would have cost. [ByKaranteli dataset inventory](https://bykaranteli.com/data) · [Trawl Jupiter archive description](https://trawl.run/data/jupiter-perpetuals) · [Jupiter swap quote fields](https://developers.jup.ag/docs/guides/how-to-build-a-custom-swap-with-metis)

No JLP paper returns were calculated. The missing inputs are dated pool and custody states, matched executable swap prices, and enough consecutive held-out periods to separate fee income from directional beta and trader P&L. The named managed vault uses its own sizing and hedging, so its reported returns would measure a different strategy.
